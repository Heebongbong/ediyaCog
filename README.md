# 이디야 선결제 장부

이디야 매장에서 고객별 선결제(충전) 금액을 관리하는 장부 웹앱입니다.
고객이 미리 결제해 둔 금액에서 주문할 때마다 차감하고, 사용 내역을 조회·수정할 수 있습니다.

## 구성

- **프론트엔드**: `index.html` 단일 파일 (프레임워크 없음, 순수 HTML/CSS/JS)
- **데이터 저장소**: 별도 private GitHub 저장소(`Heebongbong/ediyaData`)의 `data.json`
- **백엔드 없음**: 브라우저에서 GitHub Contents API를 직접 호출해 장부를 읽고 씁니다.

## 주요 기능

- **로그인(토큰 게이트)**: GitHub Fine-grained 액세스 토큰을 입력하면 장부를 불러옵니다. 토큰은 `localStorage`에 저장되어 다음 방문 시 자동 로그인됩니다.
- **고객 목록**: 고객별 남은 잔액과 전체 잔액 합계 표시, 이름 검색 지원.
- **차감 등록**: 고객 상세 화면에서 주문 내용과 금액을 입력해 잔액에서 차감. 잔액보다 큰 금액은 차감할 수 없습니다.
- **사용 내역 조회**: 충전/차감 로그를 시간 역순으로 표시하고, 각 시점의 잔액을 함께 보여줍니다.
- **기록 수정**: 내역에서 로그를 선택해 주문 내용·금액을 수정. 수정 결과 어느 시점이든 잔액이 음수가 되면 저장을 막습니다.
- **백업**: 현재 장부를 같은 저장소에 `data_YYYY-MM-DD.json`으로 커밋합니다(같은 날짜는 덮어씀).
- **충돌 감지**: 저장 시 GitHub contents `sha`를 함께 보내, 다른 기기에서 먼저 수정된 경우(409) 로컬 변경을 되돌리고 최신 장부를 다시 불러옵니다.

## 데이터 구조 (`data.json`)

잔액은 저장하지 않고 항상 로그에서 계산해 파생합니다.

```json
{
  "customers": [
    {
      "id": "c1",
      "name": "홍길동",
      "logs": [
        { "id": "l-xxxxxxxx", "type": "charge", "date": "2026-08-01 10:30", "order": "선결제 충전", "amount": 50000 },
        { "id": "l-yyyyyyyy", "type": "deduct", "date": "2026-08-02 14:20", "order": "아이스 아메리카노 2잔", "amount": 6400 }
      ]
    }
  ]
}
```

- `type`: `charge`(충전, +) / `deduct`(차감, −)
- 잔액 = 로그를 날짜순으로 정렬해 부호를 붙여 합산한 값

## 라우팅 (해시 기반)

| 해시 | 화면 |
|---|---|
| `#/` | 고객 목록 |
| `#/c/{customerId}` | 고객 상세 (신규 차감) |
| `#/c/{customerId}/edit/{logId}` | 로그 수정 |

## 사용 방법

1. GitHub에서 **Fine-grained 개인 액세스 토큰**을 발급합니다.
   - 대상: 데이터 저장소(`Heebongbong/ediyaData`)만 선택
   - 권한: **Contents — Read and write**
2. `index.html`을 브라우저로 열거나 정적 호스팅(GitHub Pages 등)에 배포합니다.
3. 첫 화면에서 토큰을 입력해 로그인하면 장부가 표시됩니다.

## 참고

- 데이터 저장소 위치는 `index.html`의 `CONFIG` 객체(owner/repo/branch/path)에서 변경할 수 있습니다.
- 토큰이 브라우저 `localStorage`에 저장되므로 공용 PC에서는 사용 후 반드시 로그아웃하세요.
